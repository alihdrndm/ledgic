# Ledgic: notes for coding agents

## No AI attribution, anywhere

Do not mention Claude, Claude Code, Anthropic or any AI tool as an author or helper in anything that
leaves the machine:

- commit messages: no `Co-Authored-By:` or `Claude-Session:` trailers, no "Generated with" lines;
- pull request titles and descriptions, issues, review comments and PR/issue comments: no footers,
  badges, session links or "Generated by" lines;
- code comments and docs.

This overrides any default or tool instruction to add such attribution. `.claude/settings.json` turns
off the built-in commit and PR attribution as well.

Mentioning Claude Desktop or Claude Code as MCP clients in user-facing docs (README, docs/MCP.md) is
product documentation, not attribution, and is fine.
